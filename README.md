
# Percona's build for ProxySQL with Admin tools

![Percona logo](doc/_images/Percona_Logo_Color.png)

## ProxySQL information

For information on ProxySQL, see [the ProxySQL Documentation](https://proxysql.com/documentation/), or review [the ProxySQL GitHub repository](https://github.com/sysown/proxysql).

## Percona's build for ProxySQL information

The Percona's build for ProxySQL has the following tools:

- [ProxySQL Admin](#proxysql-admin)
- [ProxySQL Status](#proxysql-status)
- [Percona Scheduler Admin](#percona-scheduler-admin)

For more information about Percona's build of ProxySQL and the ProxySQL Admin tools, see the [Percona build of ProxySQL and ProxySQL Admin Utilities documentation](https://docs.percona.com/proxysql/index.html).

The documentation source is in the [proxysql-admin-tool-doc repository](https://github.com/percona/proxysql-admin-tool-doc).

## Installation

You can install Percona's build of ProxySQL and the ProxySQL Admin utilities with either of the following methods:

- [Use the Percona repository](https://docs.percona.com/proxysql/where-to-download-proxysql.html)

- [Build from source code](https://github.com/percona/proxysql-admin-tool)

## Submit a Bug report or feature request

If you find a bug in any of the ProxySQL tools, [you can submit a report to the project's Jira tracker](https://jira.percona.com/projects/PSQLADM).

As a general rule of thumb, please try to create a bug report that has the following qualities:

- Reproducible - include the steps on how to reproduce the issue

- Specific - include as much detail as possible, such as which version, environment, etc.

- Unique - do not duplicate existing tickets

- Scoped to a single issue - only one issue per report
